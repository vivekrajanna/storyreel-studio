# Contributor Covenant Code of Conduct

We are committed to providing a welcoming, respectful, and harassment-free experience for everyone contributing to StoryReel Studio.

## Expected Behavior
- Use welcoming and inclusive language.
- Respect differing viewpoints and creative styles.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the community and users.

## Unacceptable Behavior
- Harassment, personal attacks, or discriminatory remarks.
- Publishing private information, API keys, or secrets belonging to others.
- Malicious code or attempts to bypass user-controlled API budgets.

## Enforcement
Project maintainers may remove comments, commits, or contributions that violate this Code of Conduct.
